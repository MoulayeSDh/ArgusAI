# ArgusAI v0.1.0-beta — First public beta

ArgusAI is a local-first multimodal AI assistant for documents, images, local memory, OCR, optional web tools and generated artifacts.

## Highlights

- Local Ollama inference with Qdrant memory.
- PDF and image analysis with OCR support.
- Explicit, opt-in web search and URL scraping.
- Local judge pass and JSONL execution traces.
- Docker Compose support.
- Lite installation profile using two models, plus the full specialized-model profile.
- Three documented workflows: private PDF analysis, multimodal research and local coding.

## Installation

```bash
git clone https://github.com/MoulayeSDh/ArgusAI.git
cd ArgusAI
cp .env.lite.example .env
ollama pull qwen3-vl:8b
ollama pull qwen3-embedding:latest
docker compose run --rm argusai doctor
docker compose run --rm argusai
```

Windows PowerShell:

```powershell
Copy-Item .env.lite.example .env
```

See the README for the complete Docker and Python installation paths.

## Requirements

- Python 3.10+ for direct installation, or Docker Desktop for Docker Compose.
- Ollama running locally.
- Lite profile: `qwen3-vl:8b` and `qwen3-embedding:latest`.
- Full profile: the Lite models plus `deepseek-r1:8b`, `qwen3.5:9b` and `qwen2.5-coder:7b`.

## Known limitations

- This is an early beta and local hardware requirements depend on the selected models.
- The default Docker stack is designed for local development, not public exposure.
- Surya OCR remains optional and experimental; Docker includes Tesseract for the stable OCR path.
- Web tools are disabled by default and require explicit user confirmation.
- Generated artifacts must be reviewed before production use.
